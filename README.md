## 🎮 About the Game

**Game of Swords** is a dark fantasy strategy game built for the web.
Players control factions, initiate battles, and conquer territories across a stylized medieval world.

The game combines:

* 🧠 Strategy (map-based decisions)
* ⚔️ Combat (battle resolution system)
* 🎮 Real-time Duel Mode (2-player fighting)

---

## 🏰 Game Features

### 🗺️ Strategic World Map

* One Kingdom: **Aetherion**
* Four Castles:

  * Frosthold
  * Elarion Grove
  * Solkaris
  * Drakmor

---

### ⚔️ Battle System

* Select attacker and target
* Engage in cinematic battles
* Outcomes based on army strength + randomness

---

### 🎮 Duel Arena (2 Player Mode)

* Real-time combat between two players
* Controls:

  * Player 1 → WASD
  * Player 2 → Arrow Keys
* Health-based victory system

---

### 🔊 Immersive Audio

* Background theme music
* Attack, battle, and result sound effects
* Dynamic audio triggered by gameplay

---

### 🎬 Cinematic Experience

* Smooth UI transitions
* Dark fantasy visual theme
* Battle atmosphere with effects

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite)
* **3D Graphics:** Three.js
* **Audio:** HTML5 Audio API
* **Deployment:** Vercel
